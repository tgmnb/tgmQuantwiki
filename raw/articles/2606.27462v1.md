# The Decision Geometry of Covariance Estimation for the Global Minimum-Variance Portfolio under Heavy Tails

**ArXiv ID:** [2606.27462v1](https://arxiv.org/abs/2606.27462v1)

## Abstract

The global minimum-variance portfolio (GMVP) is the canonical decision built from an estimated covariance matrix, yet covariance estimators are universally evaluated by matrix-norm loss, which is not the object the decision depends on. We characterise exactly how covariance-estimation error maps into GMVP suboptimality.
