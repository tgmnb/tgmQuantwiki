# Beyond Visibility and Technical Reuse: Public Application Transformation in Open-Source Model Ecosystems

**ArXiv ID:** [2607.16687v1](https://arxiv.org/abs/2607.16687v1)
**PDF:** [https://arxiv.org/pdf/2607.16687v1](https://arxiv.org/pdf/2607.16687v1)
**Published:** 2026-07-18
**Categories:** cs.SE, cs.SI, cs.SE
**Authors:** 

## Abstract

Open-source model platforms have made it easier to publish AI models, but model release alone does not reveal whether models become visible, technically reused, or incorporated into public applications. This study introduces public application transformation as a platform-visible dimension of model impact and examines it through structured Model-Space links on Hugging Face. We construct a platform-scale dataset of 2.56 million model repositories, 1.06 million Spaces, 810,087 dataset repositories
