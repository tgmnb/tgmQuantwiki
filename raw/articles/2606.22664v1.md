# From Complaint Narratives to Monetary Relief: A Hybrid Machine Learning Framework for CFPB Consumer Complaints

**ArXiv ID:** [2606.22664v1](https://arxiv.org/abs/2606.22664v1)
**PDF:** [https://arxiv.org/pdf/2606.22664v1](https://arxiv.org/pdf/2606.22664v1)
**Published:** 2026-06-21
**Categories:** cs.CE, cs.LG, cs.CE
**Authors:** 

## Abstract

Consumer financial complaints provide a valuable source of information for identifying service failures, dispute frictions, and operational deficiencies in consumer-facing financial institutions. This paper proposes a hybrid machine learning framework for predicting monetary relief outcomes using Consumer Financial Protection Bureau complaint data. We formulate the task as an imbalanced binary classification problem, where complaints closed with monetary relief are treated as compensable outcome
