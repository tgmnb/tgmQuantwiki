## 回测参数

| 参数 | 值 |
|------|-----|
| 初始资金 | 20万 |
| 仓位规则 | 每个触发信号买入当日净值的20% |
| 持有期 | 3个交易日 |
| 入场方式 | 突破收盘买入（高开→开盘价，N字→DVC收盘价） |
| 手续费 | 最低5元 + 万三（双向） |
| 滑点 | 千八（卖出） |
| 市场过滤(B版) | 中证1000收盘价 > MA25 |

## 关键发现

1. **突破收盘买入在共享资金账户下年化73.71%**（20万→1.98亿/12.5年），验证了信号的有效性
2. **中证1000 MA25过滤降低了绝对收益**（73%→62%），但**提升了风险调整后收益**（夏普1.58→1.67），回撤从36%降至25%
3. 过滤后的胜率提升2pp（50.8%→52.8%），但信号数减少37%，仓位使用率从85%降至59%
4. 中证1000过滤在震荡市中有效筛除假信号，但在大牛市中也可能错过部分收益
