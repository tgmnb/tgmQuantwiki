## 战法核心：KDJ战法（未来一个月主框架）

### 底层逻辑

主力第一波出不完货 → 拉二波做小红顶背离新高二次出货 → KDJ勾到大负值是低价上车信号 → 散户以为是主升浪冲进去 → 主力在左峰交接筹码。

**核心口诀**：「每次过左峰的时候，一定要主动交还筹码给主力突破。上古战法说给两根就跑。」

### 适用条件

| 要素 | 条件 |
|------|------|
| **时间窗口** | 每年5-9月当中的两三个月（其他月份做此模式不挣钱或买在顶上） |
| **标的类型** | 科技/半导体/光模块板块，完成大一浪主升浪后 |
| **技术形态** | ① 25日线上站稳横盘或纠缠 ② KDJ勾到大负值 ③ 缩量纠结 |
| **买入点** | KDJ负值+25日线附近缩量（非抄底思维，做确定性） |
| **卖出点** | 每次过左峰交还筹码，不幻想二波主升浪 |
| **止损思维** | 二波本质是出货不是拉升，到左峰不走→哪来的回哪去 |

### 配合技术

- **周线MACD中大红 + 日线KDJ赋值 + B1建仓焚诀 + 百日筑基KDJ抄底技术** — 系统理解
- 「如果他是为了二次出货，那么每次过左峰的时候一定要主动交还筹码」
