# 箱体内MA26失效规则 + MACD绿柱比较法

> TGM 2026-06-30 复盘发现。基于12笔历史交易数据验证。

## 核心发现

**在箱体震荡结构中，MA26既不是支撑也不是压力，只是箱体中间的装饰线。**

## 箱体识别三特征

| # | 特征 | 阈值 |
|:-:|------|------|
| ① | 价格在窄幅区间来回震荡 | 振幅 < 25-30%（近40日） |
| ② | MA26被价格反复穿越 | ≥3次交叉/近30日 |
| ③ | MA26走平或缓慢上移 | 斜率 < 15%/30日 |

## MA26的欺骗性

| 欺骗方向 | 表现 | 案例 |
|:--------:|------|:----:|
| **假破位** | 价格在MA26下方→以为要破位→实际是箱底反弹 | **昊志机电**：06-29收MA26下4.7%→次日涨停+14% |
| **假支撑** | 价格回踩MA26→以为有支撑→实际是箱体正中 | **拓山重工**：回踩MA26(50.9)买入→次日破箱底止损-5.93% |

## ✅ 正确做法：用箱体上下沿替代MA26

- 箱体底部附近 → 考虑买入
- 箱体顶部附近 → 考虑卖出/等突破
- **MA26附近 → 忽略，不算信号**

## ✅ 例外：突破箱体后MA26恢复有效性

当价格突破箱体上下沿后，MA26重新成为有效支撑/压力。
- **海鸥股份**：突破箱体失败打回→破MA26(21.75)止损→最终跌到16.47(-25%)
- **澄天伟业**：突破箱体后MA26在57.58，价格在70.18(+22%)，趋势中MA26有效

## MACD绿柱比较法（箱体内关键信号）

> TGM发现：在箱体内，MACD绿柱的**相对长度**决定箱体方向。

### 规则

| 条件 | 含义 | 操作 |
|:----|:----|:----|
| 当前绿柱 < 前组最长绿柱（绝对值） | ⬆ **缩峰** — 空头衰竭，箱底确认 | 箱底附近可买入/持有 |
| 当前绿柱 > 前组最长绿柱（绝对值） | ⬇ **扩峰** — 空头增强，箱体可能破位 | 箱底附近减仓/止损 |

### 全量验证（2026-06-30回测）

| 案例 | 前绿峰 | 箱底绿柱 | 比较 | 结果 | 验证 |
|:----|:-----:|:--------:|:----:|:----:|:---:|
| **昊志机电** | -1.38 | -1.05 | 缩峰✅ | 涨停+14% | ✅ |
| **拓山重工**（反弹段） | -0.22 | -0.07~-0.18 | 缩峰✅ | 反弹到54.14 | ✅ |
| **拓山重工**（破位段） | -0.22 | -0.40~-0.86 | 扩峰❌ | 暴跌至46.91 | ✅ |
| **海鸥股份**（早期预警） | -0.14 | -0.05~-0.14 | 扩峰❌ | 最终暴跌至16.47 | ✅ |
| **贵研铂业** | 始终红柱 | — | 不适用 | 趋势行情 | N/A |

### 数据确认方法

```python
# 取最近60日MACD柱
# 找绿柱（< 0）的连续组
# 每组记录最负的值（peak_negative）
# 比较当前组 vs 上一组的 peak_negative：
#   绝对值缩小 → 缩峰 → 看涨
#   绝对值扩大 → 扩峰 → 看跌
```

### 适用的前提条件

1. ✅ 股票确实处于箱体震荡（按三特征识别）
2. ✅ 日线MACD有红绿交替（纯红柱或纯绿柱的趋势行情不适用）
3. 贵研铂业全程红柱→这个方法不判断，但本身说明是趋势行情而非箱体

## 实战流程

```
识别到股票在箱体震荡
    ↓
检查MA26穿越次数（≥3次则MA26失效）
    ↓
检查MACD绿柱比较
  ├── 缩峰 + 价格在箱底 → 买入/持有
  └── 扩峰 + 价格在箱底 → 准备止损/减仓
    ↓
等待价格突破箱体
  ├── 向上突破 → MA26恢复有效性
  └── 向下突破 → MA26恢复有效性（止损用）
```
