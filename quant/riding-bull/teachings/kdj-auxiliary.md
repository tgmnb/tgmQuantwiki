# KDJ辅助技巧（负值买入法 + 20以下金叉 + 三条件选股法）

> KDJ是辅助工具，配合空间技术、MACD浪型使用效果更好。三种买法：**J值负值买入**（抢反弹）、**20以下金叉**（波段起涨点）、**三条件选股法**（2026-07-06 新增·高胜率系统）。

---

## 一、J值负值买入法（原始版）

### 前提条件

**核心要求：下跌必须顺滑。**

> 顺滑 = 下跌过程中**全是阴线**，中间没有大阳线打断。

### 三种可接受形态

| # | 左侧上涨 | 下跌 | 评分 |
|:-:|:--------:|:----:|:----:|
| 1️⃣ | 顺滑上涨（MACD一浪） | 顺滑下跌 | ⭐⭐⭐⭐⭐ 最佳 |
| 2️⃣ | 涨得不顺滑 | **顺滑下跌** | ⭐⭐⭐⭐ |
| 3️⃣ | 连续涨停板 | 连续跌停板+顺滑 | ⭐⭐⭐ |

> **跌得顺滑比涨得顺滑更重要！**

### 第一步：确认死叉位置

```
死叉当天，J值必须 > 50
  → 大于50说明下跌空间够大
  → 小于50则下跌空间不足，不操作
```

### 第二步：计算买入日

| 情况 | 买入日 | 说明 |
|:----:|:------:|:------|
| **正常** | **负值第3天** | 买在开盘价/收盘价 |
| **极致** | **负值第5天** | 如果正值只走1-2天就变负，则容易走5天 |

> 负值天数从J值转为负数第一天开始算。

### 买入方式

```
① 开盘价买入（主力仓位）
② 盘中跌到4.3%位置加仓（次级仓位）
③ 收盘价买入（如果没跌到4.3%）
```

### 卖出

- 短线：当天冲7%就卖出，或次日冲高卖
- 波段：配合MACD一浪回踩买入 → 吃三浪主升浪

## 二、20以下金叉买入法

### 核心

```
KDJ的K值和D值（不看J值）在20以下金叉
  → 短期反弹或波段起涨点
```

### 使用级别

| 级别 | 用途 |
|:----:|:------|
| **日线** | 波段反弹/起涨 |
| **60分钟** | 短线反弹（配合MACD即将金叉效果更佳） |

### 配合条件

```
20以下金叉 + MACD绿柱缩短（大变小）
  + 不跌破前阴实底
  = 买入信号 ⭐⭐⭐⭐
```

## 四、2026-07-06 更新：三条件选股法（KDJ负值战法升级版）

> 2026-07-06 解盘新增方法。原始版KDJ负值买入法（仅看J值负值）胜率约34%，加上以下三个条件后胜率可达**85%以上**。

### 三条件（缺一不可）

| # | 条件 | 要求 | 说明 |
|:-:|:----|:----|:------|
| 1️⃣ | **K线结构** | **下横下结构** | 单边下跌→横盘整理→再下跌，结构完整后才考虑 |
| 2️⃣ | **MACD绿柱** | **缩短的第一根进场** | 至少三根绿柱后的某一天，MACD绿柱体开始缩短的那根K线进场 |
| 3️⃣ | **周线级别** | **MACD中红或大红** | 周线MACD必须是中红或大红（大级别趋势在上），保证大方向安全 |

### 筛选流程

```
全市场 ~3000+ 只股票
  ↓ 三条件过滤
约 80 只（符合KDJ负值+三条件）
  ↓ 进一步筛选
约 5 只
  ↓ 再筛选：市值波动率 / 历史涨停数量 / 孕线结构
约 2 只（最终建仓标的）
```

### 实战要点

- **KDJ到了负值不是买了就涨**：单独看KDJ负值买入胜率只有34%
- **必须等待绿柱体缩短的那一根**：即使KDJ到了-13（如通合科技），只要绿柱体还在放大也不进场
- **周线状态是前提**：日线选股必须基于周月趋势（周线大红/月线大红 = 大方向安全）
- **国证2000状态也重要**：指数迷迷糊糊时更要精益求精

### 与原始版的区别

| 维度 | 原始版（J值负值买入法） | 三条件选股法 |
|:----|:---------------------|:------------|
| 侧重 | 抢反弹（超短线） | 趋势延续/二波买入 |
| 胜率 | 约34%（纯KDJ负值） | 85%以上 |
| 条件 | 仅KDJ+顺滑下跌 | K线结构+MACD绿柱+周线红 |
| 时间框架 | 3-5天 | 波段（数天至数周） |
| 适用场景 | 反弹套利 | 低位埋伏趋势股/回本 |
