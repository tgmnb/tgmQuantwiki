## 二、使用战法

| 战法/技巧 | 适用场景 | 技术要点 | 原文出处 |
|-----------|---------|---------|---------|
| **KDJ战法 🆕** | 科技/半导体/光模块板块，未来1-2个月（5-9月黄金期） | 大一浪主升浪→小二浪调整→KDJ勾到大负值→25日线附近缩量纠结→黄金买入点。**核心逻辑**：主力第一波出不完货→拉二波做小红顶背离新高二次出货→KDJ负值是服务这个过程的低价上车信号 | 「每年5-9月有两三个月非常适合做这个模式」 |
| **MACD小红小绿**（参见 wiki: 分金定穴） | 任何周期，买小绿卖小红 | 🟢 小绿柱做底分型站回60日线 = 买入机会；🔴 小红柱（尤其顶背离+摸左峰）= 减仓卖出位置。不追涨不抄底，做确定性 | 「你如果想吃一个长线波段，最后这一根你总是要吃到的」 |
| **铜柱顶背离**（参见 wiki: 顶背离释放风险） | 大红接小红创新高→摸左峰 | 大红接小红→小红创新高=铜柱顶背离。**如果做了顶的回踩**（跳空回踩不破前顶）=风险释放可看多。**如果回踩漏了**=顶分型成立，阶段性见顶 | 「铜柱顶背离去摸左峰的时候就是遭遇风险的时候」 |
| **放量阳1/2线减仓法** | 持仓标的管理 | 每根放量阳线的1/2位置是关键减仓点。跌破1/2 = 减仓信号，不论是否反弹。开盘即在1/2下方=百分之百不买 | 「放量阳的1/2只要破，这就是减仓位置」 |
| **顶分型/底分型** | 判断阶段顶部/底部 | 放量阳→十字星低开→向下=顶分型成立。底分型=小绿站上60日线。顶分型成则阶段性见顶 | 「这个顶分型就跟咱们做的这个底分型一样」 |
| **周线日线大级别出货法**（深科技案例） | 持有利润垫充分的标的 | 日线放量阳1/2破=减仓，但不等于清仓。周线顶背离未出现=大级别继续持有看主升浪。**利润垫>30%可持仓不受日线波动影响** | 「我做的是周线，所以选择周线级别顶背离做大级别出货」 |
| **KDJ+MACD+B1建仓焚诀 🆕** | 周线MACD中大红+日线KDJ赋值 | 结合周线MACD中大红、日线KDJ勾到大负值、B1建仓焚诀、百日筑基KDJ抄底技术，系统理解KDJ战法。**每次过左峰主动交还筹码** | 「上古战法当中说给两根就跑」 |

### 战法核心逻辑链（骑牛登山原文提炼）

**KDJ战法的底层逻辑**：
```
主力建仓（大一浪） → 出不完货 → 
拉二波（做小红顶背离新高） → KDJ勾到大负值 = 低价上车信号 → 
散户以为是主升浪冲进去 → 主力在左峰交接筹码 → 
二波结束，套在山上
```
**吃鱼身子的关键**：买在KDJ负值+25日线缩量，卖在左峰放量。不追那一下鱼尾反弹。
