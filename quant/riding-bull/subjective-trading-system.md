# 第一卷 · 基石原理（必读一次，记在脑子里）

**这一卷不用每天翻。读一次，记到骨头里。**

## 1.1 技术骨架论（五层分析架构）

> 战法是肉，架构是骨。下单之前在心里默默过一遍五层。

```
第一层：方向（均线方向）
  └── 25日线向上→可以买，25日线向下→不买
  └── 60日线向上→大趋势安全，60日线向下→谨慎

第二层：均线状态
  └── 均线粘合（横盘）→ 准备变盘，注意方向选择
  └── 均线发散 → 鬼招手，不要追
  └── 收敛中 → 快变盘了，盯紧了

第三层：级别/浪型
  └── 月线→牛熊，周线→方向，日线→买卖时机，60分钟→精确入场

第四层：价格
  └── 定价线区间在哪？上方压制？下方支撑？左峰在哪？

第五层：量能
  └── 放量确认 = 真突破，缩量 = 假突破
```

## 1.2 时间框架优先级

```
┌────────────┬──────────┬──────────┬──────────┐
│            │ 判断方向  │ 判断强度  │ 判断时机  │
├────────────┼──────────┼──────────┼──────────┤
│ 月线       │ 牛熊定位  │ MACD红绿  │ 死不买/抢反弹 │
│ 周线       │ 趋势方向  │ MACD状态  │ 定要不要碰  │
│ 日线       │ 买卖区域  │ 扩缩趋势  │ 找买点预备  │
│ 60分钟     │ 精准时机  │ 翻红翻绿  │ 执行入场    │
│ 15分钟     │ 噪音      │ 噪音      │ 拒绝使用    │
└────────────┴──────────┴──────────┴──────────┘

规则：大周期定方向，小周期定时机。
      小周期信号不能覆盖大周期方向。
      周线红柱时，日线绿柱不减仓。
```

# 第四卷 · 买入信号（出现信号时对照）

## 模式一：倍量切（DVC）突破买入 ← 上工流程

**出现条件**：一根阳线同时切断5MA+10MA，成交量≥前日2倍。

**可操作步骤**：

```
Step 1 — 检查底座
  □ 周MACD红柱？ □ 月MACD红柱？
  → 两个都不满足 → 放弃。周月双红才做大仓位。

Step 2 — 检查信号完整性
  □ 阳线 □ 实体≥2% □ 切5MA □ 切10MA □ 倍量
  → 缺任何一项 → 不是完整DVC，不按DVC处理

Step 3 — 选买点（按优先顺序）
  ┌─ ① 突破收盘买入（最佳）：当日收盘确认后
  │   次日高开→开盘买入
  │   次日N字（open≤DVC收盘<close）→ DVC收盘价买入
  │   ✅ 回测：3天+2.33% / 胜率59.3%
  │
  ├─ ② 回踩开盘买入：
  │   等价格回踩到DVC开盘价以下，限价买入
  │   5天不触发 → 放弃
  │   ✅ 回测：3天+1.78% / 胜率43.5%
  │
  └─ ③ 盘中突破信号价买入：
      ⚠️ 收益率显著下降，不优先

Step 4 — 过滤确认
  □ 月线MACD红柱？ □ 周线DEA>0？
  → 过滤后日均信号3-4个，质量明显提升
```

**⚠️ 全量回测警告**：
- 纯DVC裸信号胜率仅45%（无正向统计优势）
- 30%信号完全失败（3天平均-4.85%）
- **不要在DVC上做K线形态过滤**——形态特征与收益相关性r<0.08，没用

## 模式二：大左峰突破 + DIF拐头 ← TGM核心模式

**出现条件**：价格突破近半年大左峰 + MACD的DIF线拐头向上。

**可操作步骤**：

```
Step 1 — 确认大左峰
  □ 找到近半年最明显的高点：_____（价格）
  □ 当前收盘价已站稳左峰上方 → 确认突破

Step 2 — 确认DIF拐头
  □ DIF连续2根上升（不看红绿柱，只看白色线）
  □ DEA在零轴上方（水上）→ 最安全

Step 3 — 确认时机
  □ 60分钟MACD翻红或绿柱缩短 → 买入

Step 4 — 仓位
  ┌─ 首次突破 + 板块强势 → 可一次性满仓
  └─ 首次突破 + 板块一般 → 半仓
```

## 模式三：大阳线回调 + 60分钟翻红 ⭐ TGM最核心买入模式

**出现条件**：一根大阳线（实体≥5%）后价格回调，不破大阳低点。

**可操作步骤**：

```
Step 1 — 审查买入条件（逐项打钩）
  □ 大阳线还活着？（次日没跌破大阳低点）
  □ 买入价在50%回撤以下？（大阳实体一半以下）
  □ 60分钟MACD翻红或缩短？
  □ 所属板块在扫描前10？
  □ 周/月MACD红柱？

  全部打钩 → 可以买
  任何一项不满足 → 不买

Step 2 — 执行
  第一枪：价格到大阳实体50%以下+60分钟翻红 → 半仓
  第二枪：继续回踩到关键定价线不破+60分钟红 → 加满

  5天不触发第二枪 → 放弃加仓，半仓持有或清仓

Step 3 — 止损
  止损位 = 大阳线低点下方3-5%
```

**⚠️ 追涨检查**（必须做）：
```
前一交易日涨幅>8% 且 今天想高开追入？
  → 先反对。这不是TGM的风格。
  → 建议：等回调到MA25附近再介入
```

**出现条件**：已有DVC或大阳线信号，价格在回调。

```

# 第五卷 · 仓位管理（下单前看）

## 5.1 账户总框架

```
总账户 ≈ 12万
每只上限 = 3万（25%）
同时最多 = 4只
合计 = 4×3万 = 12万
```

## 5.2 仓位计算器

```
今日可动用资金：___万

大盘环境：_________ → 仓位系数：___%
（强牛100% / 震荡偏强60% / 震荡偏弱40% / 弱势10%）

今日仓位上限 = 12万 × 仓位系数 = ___万
每只上限 = 仓位上限 ÷ 4 = ___万
```

## 5.3 分层买入法

**任何买入分两步走**：

```
第一枪：信号确认 + 60分钟翻红 → 买入目标仓位的50%

第二枪：价格回踩关键支撑 + 确认 + 60分钟MACD健康
       → 加仓到满

如果5天不触发第二枪 → 放弃加仓，半仓持有或清仓
```

**例外**：强势突破大左峰的首次买入，可一次性满仓。

## 5.4 仓位-止损联动表

```

# 第六卷 · 离场规则（持有期间参考）

## 6.1 止损速查

```
止损设在哪？
  ┌─ 支撑止损：定价线/左峰/MA25下方3-5%
  ├─ 递归K线止损：控制阳线最低点下方
  ├─ 时间止损：买入后3-5天不涨就走
  └─ 移动止损：随价格上涨上移

条件单怎么设？
  止损单用市价单，不用限价单
  如果必须用限价 → 设在止损价下方1-2%
  （快速下跌时限价单可能不成交）
```

# 第七卷 · 特殊模式库

## 7.1 双向入场策略（都做模式）

**适用**：周月双红的大必胜行情。

**操作**：
```
路径A（回踩买）：价格回踩MA25/关键支撑 → 买入
路径B（突破买）：价格突破大左峰/定价线 → 买入
两条路同时挂条件单
先触发哪条走哪条
中间墨迹阶段 → 不上车
```

## 7.2 缩量涨停板

**条件**：前一天放量阴线 → 今天缩量涨停。
**操作**：次日高开持有，低开减仓。

## 7.3 集合竞价抓涨停

**放量阴线法**：昨日放量阴线 → 今日集合竞价高开+量能配合。
**盘口语言法**：集合竞价盘口连续大单托底。

## 7.4 下横下（凯旋）战法

**口诀**：强势股急跌→横盘→最后一跌→L型反弹。
**卖点**：反弹到前高附近卖出。

## 7.5 黄金线/定海神针

**条件**：连板后跌停 → 第二天反包涨停。
**操作**：反包日买入，持2-3天。

## 7.6 板后系数

**操作**：涨停后分三档抄底（5%/10%/15%）。
**九不买**：不符合条件不参与。

## 7.7 妖股龙头战法

**定龙术**：板块内最先涨停的 = 龙头。
**龙首阴**：龙头第一次分歧 = 低吸机会。
**见顶判定**：量先萎缩 → 价滞涨 → 时间到 → 空间到位。

# 第九卷 · 心理法则（亏钱/踏空时读）

## 9.1 踏空风险 > 亏损风险

```
TGM交易第一驱动力：怕踏空 > 怕亏钱。

实操体现：
  宁可买了被套，也别踏空看着涨。
  洗出去→可以在支撑位买回来。
  踏空了→真追不上。
```

## 9.2 N字心理准备

```
大牛股的走势永远是N字——涨→调→涨。
第一波涨后必有回调（洗盘）。
大多数人在回调中被洗出去。

买之前想好两个问题：
  ┌─────────────────────┐
  │ 空间：回踩到哪里我不怕？│
  │ 时间：震荡多久我能等？  │
  └─────────────────────┘
  想好了再买。
```

## 9.3 腾挪空间 > 利润

```
TGM决策排序：
  ① 心理空间（有没有腾挪余地）→ ② 利润 → ③ 成本

任何时候保留至少一份现金 = 保留心理安全感。
满仓被套 = 失去决策权 → 必须避免。
```

## 9.4 洗出去再买回来

```
止损触发 = 风险管理正确执行，不是失败。
若股价回到关键支撑位 = 重新入场。
不需要对同一只股有心理阴影。
条件单设在实际技术位，不上移（怕踏空也要忍）。
```
