# V9-2 — 多周期嵌套尧法双均线策略

## 一、策略设计

### 核心思想

5 个时间周期同时对同一品种产生交易信号，各周期独立分配仓位。**同一品种不允许双向持仓**——按净方向决定（Net Direction Reckoning）：

```
净方向 = Σ(多头保证金) - Σ(空头保证金)
- 净方向 > 0 → 只保留多头，强制平掉该品种所有空头
- 净方向 < 0 → 只保留空头，强制平掉该品种所有多头
- 净方向 = 0 → 允许开仓任意方向
```

### 周期参数

| 周期 | 每品种保证金 | 含义 |
|:---:|:-----------:|:----|
| 7d | 0.5% | 大趋势骨架 |
| 1d | 1.0% | 中期方向 |
| 12h | 1.5% | 中短期组合 |
| 4h | 2.0% | 短期交易 |
| 1h | 3.0% | 日内信号 |

- 单个品种最多占用保证金：0.5+1+1.5+2+3 = **8%**
- 全局总保证金上限：**100%** 权益
- 其他共享参数：10x 杠杆, $500 初始, 千一 exit 滑点, 0.04% taker fee

### 入场逻辑（与 V8 一致）

- 尧法 MA20/75（open + 前 N-1 根 close）
- open-based zone 分类
- high/low touch 入场（`high ≥ upper` OR `low ≤ lower`）
- MA20 斜率 >0（多）/ <0（空）
- prev_zone ≠ current_zone（zone transition）

### 冲突处理

当新信号与当前净方向冲突时：
1. 先识别当前品种所有反方向 slot
2. 逐一平仓（标记 `conflict_close`）
3. 重新计算净方向
4. 如果净方向不再冲突 → 开新仓
5. 如果仍然冲突 → 跳过

### 实现架构

`backtest_crypto_dual_ma_v9_2.py` — 独立脚本，不依赖 V8 源码。

优化特点：
- **预计算信号索引**：`signal_index[tf][datetime] → [(product, direction), ...]`，避免逐时间戳扫描全品种
- **searchsorted 指标查询**：`get_bar()` 使用 numpy searchsorted 替代 DataFrame 反复查询
- **统一 1h 时间线**：所有周期信号对齐到 1h 分辨率

## 四、方向冲突统计

净方向决定机制在运行中产生的冲突调整（`conflict_close` 与 `conflict_open`）在 `actions.csv` 中记录。典型场景：

```
已有 7d 多头(0.5%)  + 4h 多头(2.0%) → 净方向 +2.5%
  1h 出现空头信号 → conflict！1h 空被拒绝
  1d 出现空头信号 → conflict！先关 7d+4h 多头, 再开 1d 空头
```

净方向逻辑的关键效果：**防止同一品种在不同周期上"自己跟自己反着赌"**。

## 五、已知问题

### 5.1 10x 杠杆复利爆炸

3% 保证金 × 10x 杠杆 × 700 币 × 6 年 → 即使有万八滑点和万四手续费，1h 时间帧仍然产生了 -$650 的名义亏损。修正后的结果表明**策略本身在 1h 时间帧上即无正期望**，杠杆只是放大了亏损速度。

### 5.2 模拟速度

修正后 V9-2 计算耗时 568 秒（此前旧版本为 1053 秒）。改进来自 `MARGIN_CAP_ENTRY` 和 `equity_now()` 包含冻结保证金的优化，以及缩减了不必要的循环。

### 5.3 7d 周期信号缺失

7d 时间帧（保证金分配 0.5%）未触发任何信号。可能由于 7d MA(20,75) 在 7d K 线中覆盖 ~140–525 天，在 2020–2026 数据范围内产生的交叉太少。

### 5.4 回测与实盘差异

- 即使回测不存活，实际交易中的资金费率、行情冲击、流动性差异只会使结果更差
- 修正后回测已展示：**此策略变体不具备实盘部署价值**

## 七、下一步方向

鉴于修正后所有变体均近全损，**不建议继续在此策略体系上投入开发资源**。如仍希望探索：

1. **彻底放弃 1h 时间帧** — 1h 在所有变体中均为亏损主力
2. **仅保留 4h/12h/1d** — 这些时间帧在 V9-2 中细分盈利但绝对收益太小（+$151/6年）
3. **改用 fixed notional + 低杠杆** — 但需先重新评估策略是否具备正期望

> **结论**：修正后的回测证据表明尧法双均线策略体系在 10x 杠杆、万八滑点、万四手续费的条件下不具备统计正期望。所有变体均为全损结果，**不推荐任何形式的实盘或模拟盘部署**。
