## 核心观点

MACD 可以重建为数学空间里的运动轨迹。**小级别 MACD 是大级别 MACD 的导数（在滤波器设计意义上）**，但这一关系不是统计回归，而是线性滤波器（EMA12-EMA26）的数学性质。

**模型预测的是 MACD 的几何结构/相位，而非 MACD 的具体数值。**

---

## 一、正确数学关系：滤波器身份，非统计回归

### 1.1 什么是 MACD？

MACD 的核心是 **DIF（差离值）**，它是一个线性时不变滤波器：

```
DIF(t) = EMA12[price(t)] - EMA26[price(t)]
```

对于同一个价格过程 p(t)，在不同采样率下计算 DIF：
- 日线 DIF：从日线收盘价 p_日[n] 计算
- 周线 DIF：从周线收盘价 p_周[k] 计算
- 月线 DIF：从月线收盘价 p_月[m] 计算

它们是**同一个线性滤波器在不同采样率下的输出**，之间的关系由滤波器的频率响应决定——不是统计拟合出来的。

### 1.2 正确形式（v2）

```math
DIF_时(t) ≈ [DIF_日(t) - DIF_日(t-1)] · f(EMA参数)
```

其中：
- f(EMA参数) 由 EMA12-EMA26 的离散频率响应函数决定
- 这是一个 **滤波器设计参数**，不是 **统计拟合参数**
- 不需要回归 R² 来验证

### 1.3 多周期零轴穿越是理论自洽的

实测数据（6只个股，全部历史）：

| 标的 | 日线翻红 | 周线翻红 | 月线翻红 | 日/周比 | 日/月比 |
|:----|:-------:|:-------:|:-------:|:------:|:------:|
| 贵州茅台 | 95次 | 19次 | 5次 | 5.0x | 19.0x |
| 宁德时代 | 30次 | 5次 | 4次 | 6.0x | 7.5x |
| 澄天伟业 | 44次 | 8次 | 2次 | 5.5x | 22.0x |
| 金钼股份 | 71次 | 16次 | 4次 | 4.4x | 17.8x |
| 招商银行 | 108次 | 20次 | 5次 | 5.4x | 21.6x |
| 五粮液 | 101次 | 22次 | 4次 | 4.6x | 25.2x |

**日/周比 ≈ 5x（理论 = 约5个交易日/周），日/月比 ≈ 20x（理论 = 约22个交易日/月）**。这验证了滤波器身份关系不需要统计拟合来"证明"——它是数学自洽的。

## 二、相空间与螺旋

### 2.1 三维相空间

将 DIF(日线), DIF(周线), DIF(月线) 正规化（去量纲）后，在三维空间中追踪轨迹。每个时间点对应一个点 (dif_日_norm, dif_周_norm, dif_月_norm)。

**实际形态**（vs v1 的理想椭圆螺旋）：

| 特征 | v1 声称的理想螺旋 | v2 实测 |
|:----|:----------------|:--------|
| 轨迹形状 | 椭圆螺旋线，绕原点旋转 | 波段往复，非完美椭圆 |
| 相位演化 | φ 连续变化，匀速旋转 | φ 有跳变，受噪声干扰 |
| 相位差 | 精确 90° | 约 60-120°，不恒定 |
| 半径趋势 | 周期性扩展收缩 | 存在但非线性 |

**实测定性结论**：三维相空间存在结构（不是随机噪声），但不是完美的椭圆螺旋。更像是一个**低维吸引子**——轨迹在两个象限之间往复运动而不是绕原点匀速旋转。

### 2.2 相位象限仍然有意义

从正规化 (DIF_日, DIF_周) 二维投影中提取相位角：

```
φ = atan2(DIF_日_norm, DIF_周_norm)
```

| 相位 φ | 第几象限 | 阶段 | 含义 |
|:------:|:--------:|:----|:-----|
| 0°~90° | 第一象限 | **扩张** | 日线>0, 周线>0，双周期共振上涨 |
| 90°~180° | 第二象限 | **衰减** | 日线<0, 周线>0，短期转弱但中期仍强 |
| 180°~270° | 第三象限 | **收缩** | 日线<0, 周线<0，双周期共振下跌 |
| 270°~360° | 第四象限 | **复苏** | 日线>0, 周线<0，短期转向但中期未确认 |

### 2.3 螺旋半径 R = 趋势强度

```math
R = √(dif_日_norm² + dif_周_norm² + dif_月_norm²)
```

R 的扩张/收缩 = 趋势的加速/衰竭。

实测趋势（% + 表示扩张，% - 表示收缩）：
- 茅台: +0.51/1000天（长期螺旋在扩张）
- 金钼: -0.46/1000天（长期螺旋在收缩）
- 澄天: -0.23/1000天

R 在高位时趋势达到顶峰，R 在低位时趋势极度衰竭。R 的扩张与收缩周期与已知的大市行情高度吻合。

### 2.4 偏离度 d = 异常检测

滑动窗口 PCA 残差 = 当前点到螺旋吸引子的垂直距离。

- **高偏离度** → 价格已大幅偏离周期性路径，趋势转折前兆
- **低偏离度** → 价格沿周期路径正常演化

实测：**偏离度 P95 点与趋势转折高度吻合**，例如茅台 2021 年的偏离度峰值精准对应顶部转折。

## 三、模型预测目标（神人原意）

### 3.1 正确理解："预测 MACD 而不是预测股价"

神人的模型预测的是：

| 预测什么 | 解释 | 状态 |
|:--------|:----|:----|
| ✅ 当前在螺旋的什么位置 | 相位象限 + 半径大小 | v2 已验证可用 |
| ✅ 螺旋在扩张还是收缩 | 趋势加速 vs 衰减 | v2 已验证 |
| ✅ 当前偏离螺旋多远 | 异常信号 → 转折前兆 | v2 已验证 |
| ❌ 明天 MACD 值是多少 | 数值点预测 → 被 v1 错误测试 | 不可用 |
| ❌ 明天股价涨还是跌 | 股价预测 | 超出模型范围 |

### 3.2 什么是"结构性分析" vs "量化点预测"

```
结构性分析（正确）        量化点预测（错误，v1测了错的东西）
┌──────────────┐          ┌──────────────────────┐
│ 趋势在加速吗？          │ 明天MACD值是多少？    │
│ 三周期共振吗？          │ 方向一致率多少？      │
│ 偏离度高了 → 转折？     │ R²拟合度多少？       │
│ 当前仓位合宜吗？         │ 回归系数显著吗？     │
└──────────────┘          └──────────────────────┘
```

## 四、v1 错误建模的自我检讨

v1 版（2026-06 初稿）包含两个根本错误：

### 错误 1：把滤波器设计关系当成统计回归

**v1 写的是：**
```
d(MACD_日)/dt = k₁ · MACD_60分
```
然后用线性回归拟合 k₁，用 R² 和方向一致率（50.6%）验证——得到了"抛硬币"的结论。

**问题：** 这是一个线性滤波器的信号处理身份关系，不是统计假设。回归寻找 k 本身就是错误的——EMA12-EMA26 的耦合由滤波器频率响应确定，不是由数据拟合确定。

### 错误 2：把结构性分析框架当成量化点预测模型去回测

神人说"模型预测 MACD 不是预测股价"，v1 的实证测的是"明天 MACD 涨还是跌"的方向一致率。但螺旋模型预测的是**MACD 在三维相空间中的几何/拓扑性质**（相位位置、半径扩张/收缩、偏离度），不是"明日数值"。

v1 的实证从根上就测错了目标。

### 教训

| v1 做法 | 正确做法 |
|:--------|:--------|
| 拟合 k 系数 | 直接推导 f(EMA参数) 的解析形式 |
| 回归验证 R² | 验证多周期零轴穿越比例自洽 |
| 统计方向一致率 | 验证相空间结构、半径趋势 |
| 求数值预测精度 | 求结构/相位的合理性 |

## 五、实用指南：怎么用这个框架

### ✅ 可用的用法

1. **三线红判断** — 所有周期（日/周/月）DIF > 0 → 趋势共振强。实测：茅台三线红占比 34%，澄天仅 10%
2. **螺旋半径趋势** — R 持续扩大 → 趋势加速中；R 持续缩小 → 力度衰竭，准备防守
3. **偏离度报警** — 偏离度达 P95 高位 → 趋势可能转折，检查顶/底背离
4. **相位定位** — 当前处于扩张/衰减/收缩/复苏哪个阶段，指导仓位

### ⚠️ 需要谨慎的用法

1. **过度数学化** — 这不是一个可以用公式精确预测的模型，是定性分析框架
2. **短周期预测** — 小时线级别的信号受噪声干扰太大（已实证）
3. **机械交易** — 不能直接转化成开仓/平仓条件

### ❌ 不能用的用法

1. **k 系数拟合** — 滤波器关系不适用统计回归
2. **方向一致率验证** — 测了错误的目标
3. **MACD 数值点预测** — 模型没有这个能力

## 七、吸引子的变化与稳定性（2026-07-01 新增）

> 数据日期：2026-07-01
> 分析脚本：`~/quant/research/macd_helix_v2/helix_v2_attractor_change.py`
> 统计结果：`output/attractor_change_summary.json`

### 7.1 核心问题

"吸引子不变，无论多远都会被吸引回来"——这个直觉对吗？

**答案：基本正确，但需要区分两种"离开"。**

---

### 7.2 两种不同类型的"吸引子变化"

#### 类型 A：脉冲偏离（航天发展型）

- **表现**：轨迹猛烈冲出吸引子（暴涨），然后迅速回归（暴跌）
- **时间尺度**：数月~数年
- **本质**：吸引子本身没变，是轨迹去做了一次"往返跑"
- **检测**：离开率瞬间冲到 60-100%（远超 P95=5%），暴跌后回到接近 0
- **可预测性**：✅ 可用快速变动信号提前预警

#### 类型 B：缓慢漂移（茅台型）

- **表现**：吸引子中心在日/周/月 DIF 空间中缓慢、持续地朝一个方向移动
- **时间尺度**：数年~数十年
- **本质**：公司的基本面变了，市场对它的定价逻辑变了，所以"正常状态"变了
- **检测**：中心漂移持续 > 0.5σ，离开率缓慢上升并长期维持在高位
- **可预测性**：❌ 不可预测（基本面驱动），但可监测（每年重估基线）

---

### 7.3 怎么区分？

| | 脉冲偏离（飞天型） | 缓慢漂移（茅台型） |
|:--|:----------------:|:----------------:|
| 中心位置 | 震荡，不持续移动 | **持续朝一个方向移** |
| 离开率 | 突然冲高又回落 | **缓慢上升，长期高位** |
| 股价 | 暴涨→暴跌 | 长期趋势变化 |
| 判断方法 | 看离开率是否回落 | 看中心是否持续漂移 |

**关键检测指标：**

1. **中心漂移（Center Drift）** — 滚动吸引子中心到基线中心的欧氏距离。如果持续 > 0.5σ → 吸引子在漂移。
2. **离开率（Exit Rate）** — 窗口内离开基准吸引子的比例。理论 5%（P95 边界），实际 > 20% → 状态异常。
3. **距离比（Mahalanobis Ratio）** — 基准马氏距离中位数 / 滚动马氏距离中位数。> 2 → 当前分布和基线分布有明显差异。

### 7.4 全样本统计（155只有效）

| 统计项 | 数值 |
|:------|:----:|
| 出现过显著吸引子变化（漂移>0.8σ 或 离开率>20%） | **96%** |
| 出现过中度变化（漂移>0.5σ 或 离开率>10%） | **100%** |
| 平均最大中心漂移 | **2.14σ** |
| 平均最大离开率 | **53.7%** |
| 平均窗口离开率 | **22.8%**（理论 P95=5%） |

**解读：** 几乎所有股票在足够长的时间尺度下都经历过吸引子变化。这也是自然的——A 股很少有公司上市 20 年业务不变。但大多数变化是**缓慢的**（经年累月），而不是突然的。

### 7.5 变化信号的交易价值

| 信号 | 含义 | 20天后平均收益 | 胜率 | 触发次数 |
|:----|:----|:-------------:|:---:|:-------:|
| ratio_high | 当前分布与基线分布显著不同 | **+2.17%** | 58% | 24次 |
| any_high | 任意变化信号触发 | **+1.66%** | 50% | 64次 |
| drift_high | 中心漂移过大 | **+1.07%** | 54% | 24次 |

**结论：** 吸引子变化后，市场倾向于**沿新状态方向惯性运行**（而不是立刻回归）。变化信号可作为"状态切换后的惯性交易"参考。但触发次数太少（24次在155只股票的全历史中），不宜作为独立交易系统。

### 7.6 对交易的启示

```
1. 股票不同于 → 吸引子稳定 → 用三线红/相位象限/偏离度诊断
2. 股票在变化 → 等待新吸引子形成 → 适应新状态的交易策略
3. 暴涨暴跌 → 不是吸引子变化 → 等它弹回来再用状态诊断

实测最有效的用法：
- 监视滚动吸引子 vs 基线吸引子的差异度 (ratio)
- ratio_high 触发后 → 新状态惯性交易机会
- 但信号不频繁，适合做辅助确认层
```
