## 核心思想

价格运行以**状态（regime）为单位**。在一个状态内，价格在一个多维空间的"面"上波动；当外界信号（如基本面信息变化）打破现有状态时，价格**跃迁**到新的面上。

这不是预测模型，是**环境感知系统**。

---

## 数学框架

### 1. Markov 切换模型（Hamilton 1989）

$$dP_t = \mu_{S_t} \cdot P_t \cdot dt + \sigma_{S_t} \cdot P_t \cdot dW_t$$

- $S_t \in \{1, 2, ..., K\}$：离散状态变量（regime），服从 Markov 链
- 每个状态有独立的漂移 $\mu$ 和波动率 $\sigma$
- 状态切换由转移概率矩阵 $p_{ij}$ 控制

### 2. 势能景观（Potential Landscape）

每个状态对应势能函数 $V(x)$ 的一个局部极小值（势阱）：

$$F(x) = -\frac{dV}{dx}$$

- 价格 = 在势阱内振动的粒子
- 外部信息冲击 → 势阱变浅/倾斜 → 粒子跳到另一个势阱
- **跃迁 = 势能景观拓扑结构变化**

### 3. 分岔理论（Bifurcation Theory）

外部参数连续变化到临界值时，系统定性行为突然改变：

- **鞍结点分岔**：稳定点和不稳定点碰撞消失，系统被迫跳到远处的稳定点
- **Hopf 分岔**：稳定点变成极限环，价格从震荡变趋势

## 工程实现路径

### 路径一：纯数值流形（推荐先做）

**数据源：** 价格、成交量、个股、板块、指数、所有技术指标

**步骤：**

1. **构建特征向量**（每个标的每天一个）
   - 价格特征：收益率、波动率、偏度、峰度
   - 量价特征：量比、换手率、量价相关性
   - 技术指标：MACD、KDJ、RSI、布林带位置、均线斜率
   - 跨市场特征：板块相对强弱、指数 beta、板块轮动信号
   - 维度：20-50 维

2. **降维建流形**
   - UMAP（保留局部结构好）或 Diffusion Map（全局结构好）
   - 降到 2-3 维

3. **聚类识别状态**
   - HDBSCAN 或 Gaussian Mixture
   - 每个簇 = 一个市场状态（牛市趋势/熊市趋势/震荡/恐慌/修复）

4. **状态变化检测**
   - 标的从一个簇移动到另一个簇 = 状态切换
   - 流形基线漂移 = 宏观状态变化

5. **价格边界计算**
   - 每个状态簇内做条件分布拟合
   - 布林带升级版：状态条件下的条件分位数
   - 状态转换时重置边界

### 路径二：语义流形（进阶）

**数据源：** 财经新闻、研报、公告文本

**步骤：**

1. 文本 embedding（BGE-M3 等模型）
2. 基线流形构建（60 天滚动窗口）
3. 新文本投影 + 漂移检测
4. 语义流形与价格流形的**不一致信号** = 领先指标

## 能力边界

### 能做的

| 能力 | 说明 |
|------|------|
| 状态识别 | 告诉你"现在是什么状态"——牛市/熊市/震荡/恐慌 |
| 状态切换检测 | 检测状态何时变了，比价格变化更早 |
| 状态条件价格边界 | 不是固定支撑/阻力，而是当前状态下的条件分布 |
| 仓位管理 | 不同状态对应不同仓位上限和止损策略 |
| 信号过滤 | 同一信号在不同状态下效果不同，流形帮你判断该不该信 |

### 不能做的

| 局限 | 说明 |
|------|------|
| 预测价格方向 | 流形告诉你状态，不告诉你涨跌 |
| 预测状态跳变时点 | 能检测到跳已经发生，不能提前预测 |
| 替代选股 | 流形是宏观/中观工具，不告诉你买哪只股票 |

## 量化交易应用

### 1. 仓位管理（最直接）

```
状态 = 流形识别出的当前 regime
if 状态 == "牛市趋势":
    仓位上限 = 90%，止损宽松
elif 状态 == "震荡":
    仓位上限 = 40%，止损严格
elif 状态 == "熊市趋势":
    仓位上限 = 10%，以空仓为主
```

### 2. 状态条件信号过滤

- 牛市状态下金叉买入 → 胜率高，可以跟
- 熊市状态下金叉买入 → 大概率假信号，过滤掉

### 3. 状态转换交易

检测到状态跳变（震荡→牛市趋势）= 交易信号，调整策略

## 与文艺复兴基金的关系

文艺复兴（Renaissance Technologies）确实使用类似框架：

- ✅ 使用隐马尔可夫模型（HMM）识别市场状态
- ✅ 不同状态使用不同参数模型
- ✅ 检测状态转换的临界信号

但：

- ❌ 不是用 embedding/NLP 做的（黄金期在 90-2010 年代）
- ❌ 框架本身不是秘密（公开学术方法）
- 真正优势：数据积累、执行能力、过拟合控制、保密性
