## 一、原理

### 1.1 核心思想

> **每个市场状态都有自己的"吸引子" → 工程控制论检测状态跃迁 → 刚跃迁的时刻是介入机会**

这套框架源自"神人"（一个数字领域研究者）的观点：
> MACD可以重建成数学空间里的运动轨迹，是一个DNA似的螺旋结构，小级别MACD是更大级别的导数

神人的原始思路：用MACD的多时间框架（日/周/月DIF）构建三维相空间，每个周期循环对应一个相位（扩张→衰减→收缩→复苏）。我们的扩展：从三维MACD扩展到五维多指标相空间，从螺旋几何转向**工程控制论的状态跃迁检测**。

### 1.2 吸引子是什么

在数学/物理中，吸引子（attractor）是动力系统趋向的长期稳定状态。

**在交易中的应用**：把股票的历史行情看作在"指标空间"中运动的一个点。这个点不会随机乱跑，而是被一个"吸引子"约束在一个区域。当吸引子本身发生变化时，系统进入了一个新的运行状态——这就是**状态跃迁**。

### 1.3 为什么用5个指标

| 维度 | 指标 | 捕捉什么 | 来源 |
|:----|:----|:--------|:----|
| dim0 | **MACD柱** (2×(DIF-DEA)) | 动量加速度 | K线收盘价 |
| dim1 | **OBV** (20日偏离) | 量价配合/能量潮 | 收盘价+成交量 |
| dim2 | **RSI** (14日) | 超买超卖/相对强弱 | 收盘价 |
| dim3 | **ROC** (20日变化率) | 价格加速度 | 收盘价 |
| dim4 | **Vol-Ratio** (20日均量比) | 交易活动强度 | 成交量 |

五个指标覆盖了动量、量能、强弱、加速度、活跃度——比单一MACD更全面地描述市场状态。

**为什么不是三个MACD时间框架（原版神人方法）**：经过实证对比，5个不同维度的指标比3个时间维度的同一指标效果更好（见本文第3.1节）。

## 二、方法步骤

### 2.1 算法总览

```
原始OHLCV数据
    ↓
计算5个指标的z-score → S(t) = [MACD柱_z, OBV_z, RSI_z, ROC_z, VR_z]
    ↓
滑动窗口(60天) → 提取本地吸引子属性
    ↓
窗口每5天滑一次 → 检测特征突变
    ↓
突变综合强度 > 2σ → 跃迁事件
    ↓
判断方向(5维综合) → 上行/下行/持平
    ↓
等待5天确认 → 方向没有反转 → 发信号
```

### 2.2 5D状态向量

每个交易日 t，计算5个指标后做z-score标准化：

```python
S(t) = [MACD柱_z, OBV_z, RSI_z, ROC_z, Vol-Ratio_z]
```

z-score使不同量纲的指标可比（mean=0, std=1）。标准化用**膨胀窗口**（expanding window从第60天开始）避免未来信息偏误。

**MACD柱计算**：
```python
DIF = EMA12 - EMA26
DEA = EMA9(DIF)
MACD柱 = 2 × (DIF - DEA)
```

### 2.3 滑动窗口本地吸引子

```
参数:
WINDOW = 60    # 窗口大小（交易日）
STEP   = 5     # 步长（交易日）

对每个窗口:
1. 取连续60天的5D状态向量 → 组成点集
2. 计算:
   - 吸引子中心 (center) = 点集的均值向量（5D）
   - 吸引子体积 (volume) = log|Σ|，协方差行列式的对数
   - 主成分比 (eig_ratio) = λ₁/λ₂，最大/次大特征值比
   - 粗糙度 (roughness) = 相邻点间平均距离
```

### 2.4 跃迁检测

对每个特征的变化率做z-score：

```python
ΔX[t] = X[t] - X[t-1]      # 特征变化量
z(ΔX[t]) = (ΔX[t] - μ(ΔX)) / σ(ΔX)  # z-score

综合跃迁强度 = √((z²中心 + z²体积 + z²粗糙度) / 3)

if 综合跃迁强度 > 2.0:
    → 标记为跃迁事件
```

选择2.0σ作为阈值是因为这代表各特征同时偏离正常变化范围2个标准差以上，对应约2.5%的概率——确保跃迁是**稀有事件**。

### 2.5 方向判断（5D综合）

```
Δcenter = center[窗口_i] - center[窗口_i-1]  # 5D位移向量
方向得分 = sum(Δcenter[0] + Δcenter[1] + ... + Δcenter[4])  # 全部5维求和

if 方向得分 > +0.3: 方向 = 上行
if 方向得分 < -0.3: 方向 = 下行
else:               方向 = 持平
```

为什么不用单一MACD轴方向（v4做法）：MACD存在背离现象，单一维度判断会导致方向判断错误。用全部5维综合方向更鲁棒。

### 2.6 M2确认机制（关键改进）

```
事件流程:
T日     → 跃迁检测到，方向=上行
T+5日   → 检查此时吸引子方向是否仍为上行
          如果仍是上行 → 确认，发信号
          如果转为下行 → 取消（假跃迁）
```

这个5天等待期大幅提升了信号质量：
- 跃迁后方向维持5天以上 → 确认是真正的状态切换
- 跃迁后立即反转 → 滤除

**实测效果**：

| 方法 | 分离度 | 说明 |
|:----|:-----:|:----|
| M1 单次跃迁 | +13.67% | 基线 |
| **M2 跃迁+5天确认** | **+29.04%** | **最佳** |
| M3 状态保持 | +24.80% | 信号太多稀释 |
| M4 预警过滤 | +7.44% | 过度过滤 |

### 2.7 聚类

相邻跃迁(≤2个窗口=10天内)合并为一次跃迁事件。

## 三、实验结果

### 3.1 三个MACD值的对比

MACD指标有三个值：DIF(快线)、DEA(慢线/信号线)、MACD柱(直方图=2×(DIF-DEA))。
分别替换到5D状态空间的第1维，其余4维不变：

| 方案 | MACD维度 | 上行+20d均值 | 下行+20d均值 | 分离度 |
|:----|:--------|:-----------:|:-----------:|:-----:|
| **A: MACD柱 ✅ 选定** | 2×(DIF-DEA) | **+9.8%** | **-0.6%** | **10.4%** |
| B: DIF | EMA12-EMA26 | +8.2% | +0.4% | 7.8% |
| C: DEA | EMA9(DIF) | +10.7% | +0.7% | 10.0% |

MACD柱在茅台、宁德、金钼上上行收益最强，且是唯一在茅台上下行方向正确分离的方案。

### 3.2 6D(加价格) vs 5D

在5D基础上增加第6维 `Price_z`（日收益率z-score）：

| 方法 | 5D | 6D | Δ |
|:----|:--:|:--:|:-:|
| M2上行+20d | **+23.48%** | +22.57% | -0.91% |

价格信息已内嵌在5个指标中（MACD柱含动量、ROC是价格加速度），加作为独立维度不增加价值。

### 3.3 400只A股全量验证

在400只随机抽取的A股上验证（5718只中随机抽选，seed=42）：

**结果：M2(上行跃迁+确认) 400/400只全部分离度为正**

| 统计量 | 上行+20d | 下行+20d | 分离度 |
|:------|:-------:|:-------:|:-----:|
| **均值** | **+23.48%** | **-6.02%** | **+29.04%** |
| 中位数 | +19.64% | -5.27% | +24.69% |
| Q25 | +13.31% | -9.12% | +17.76% |
| Q75 | +28.23% | -2.62% | +35.24% |
| 正值比例 | **99.5%** | **12.7%** | **100.0%** |

解读：99.5%的股票在上行跃迁+确认后+20d均值为正收益。87.3%的股票在下行跃迁+确认后+20d均值为负收益。

## 六、已知问题

### 6.1 z-score标准化偏误

`precompute_signal.py` 中z-score用了全历史均值/标准差，不是膨胀窗口。影响：
- 早期（前60个交易日）：约5-10%的年化高估
- 2017年后：影响<2%
- 整体结论不变，方向判断不受影响

### 6.2 澄天伟业类标的失效

震荡型标的（横盘震荡，无明显趋势）的跃迁信号40-50%方向错误。框架对趋势型和事件型标的最有效，对震荡型无效。

### 6.3 价格边界预测精度不足

KNN最近邻法预测价格边界的Q05-Q95命中率65%。
方向判断可用，精确价格边界不可靠。
建议只使用方向+幅度分布做决策。
