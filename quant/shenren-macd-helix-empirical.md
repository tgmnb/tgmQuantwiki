## 结论：什么是对的，什么不是

### ✅ 神人的直觉在以下方面正确

1. 不同时间尺度的 MACD 存在由滤波器性质决定的数学关系
2. 日/周/月 MACD 构成一个有结构的三维空间（低维吸引子）
3. 相位（扩张/衰减/收缩/复苏）是判断趋势阶段的有用框架
4. 这个框架是**定性分析工具**，不是量化预测器

### ❌ 以下是不对的

1. "完美 DNA 螺旋"——实际轨迹不是理想椭圆螺旋，是波段往复
2. "精确相位差 90°"——实际相位差在 60-120° 之间波动，受噪声干扰
3. "可以作为量化模型回测"——这是结构性框架，不是预测模型
4. "导数链逐级积分可推算未来"——离散噪声破坏了积分路径

## 快速变动检测（v2 新增）

数据日期：2026-07-01
分析脚本：`~/quant/research/macd_helix_v2/helix_v2_rapid_change.py`
输出图：`output/rapid_change_*.png`
预警效果：`output/rapid_change_stats.md`

### 核心思路

不是看信号到了多少，而是看它变化**有多快**。

三个核心变化率信号：
- **Δ马氏距离/Δt（10天窗口）** — 状态异常加速
- **Δ半径/Δt** — 趋势力量变化速度
- **方向性加速（方向×Δ马氏）** — 上涨/下跌方向确认

检测方法：变化率超过历史P95阈值 → 触发快速变动报警。多个信号同时触发 → 综合预警计数升高。

### 关键发现：分水岭在标的波动模式

| 标的类型 | 例子 | Δ马氏向上加速→5d胜率 | Δ马氏向上加速→20d胜率 | 结论 |
|:--------|:----|:-------------------:|:--------------------:|:----|
| **事件驱动型**（爆炸/题材） | 航天发展 | **90%（均+18.2%）** | **100%（均+71.6%）** | ✅ **有效领先信号** |
| **趋势驱动型**（稳定蓝筹） | 贵州茅台 | 40%（均-1.4%） | 45%（均-0.0%） | ❌ 接近随机 |

**航天发展的完整预警链（2025年暴涨案例）：**
1. **T-30天**：半径变化率转正（从零轴下方持续上行）→ 波动结构开始改变
2. **T-20天**：Δ马氏距离首次快速上升（红色填充区出现）→ 状态异常加速
3. **T-15天**：方向性加速度翻正（蓝色线>0）→ 上涨方向确认
4. **T-10天**：综合预警计数从0→1→2（多个信号同时触发）
5. **T-0天**：股价开始暴涨（从10到40+），马氏距离飙至100+

**结论：**
- 快速变动信号对**事件驱动型/爆炸型**标的（航天发展类）是**极其有效的预警工具**——暴涨前2-3周就可以看到信号累积
- 对**趋势驱动型/稳定型**标的（茅台类）**无效**——因为稳定标的本身很少剧烈变化，信号信噪比太低
- 差异本质：**"波动率突变" vs "波动率稳定"**。快速变动检测测的是"变"，不变的东西测不到

### 实战建议

```
快速变动监控 → 只用在火箭型/题材型/爆炸型标的上
                ↓
           Δ马氏10d加速(红色填充) + 预警计数≥2
                ↓
           方向性加速度确认(正=向上突破, 负=向下突破)
                ↓
           入场/出场决策参考
```

在茅台上用这招白费功夫——它不变，信号全是噪音。在航天发展这种"两年横盘一根线拉十倍"的标的上才是正确用法。

### 最重要的发现：加速信号在200只上是反向指标

**在航天发展上**，加速信号（Δ马氏10d）暴涨前90%胜率——因为它是个例（两年横盘后一根线拉十倍）。

**在200只上**，同样的信号平均表现为：

```

Δmahal_norm_10d_up_20d: 均收益 -1.77%，胜率 42%
Δradius_10d_up_20d: 均收益 -0.21%，胜率 44%
```

**原因：** 大多数股票的加速信号触发时不是主升浪启动，而是短线脉冲到这个位置已经该回调了。整体呈现**均值回归**而非趋势延续。

## 方法演进

### v3: 无方向跃迁检测（弃用）

- 5D状态向量 `[MACD-DIF_z, OBV_z, RSI_z, ROC_z, Vol-Ratio_z]`
- 滑动窗口(60天)提取本地吸引子属性（中心/体积/形状/粗糙度）
- 综合跃迁强度 = `√(mean(z²_center, z²_volume, z²_rough))`
- > 2σ 标记为跃迁事件
- **问题：不区分方向** → 把所有跃迁混在一起检验，航天涨了说有效，澄天跌了也说有效

### v4: 分方向（1D MACD-only）

- 跃迁方向 = `sign(Δcenter_MACD-DIF)` — 只看吸引子中心在MACD-DIF轴上的位移
- **问题：MACD背离时方向反了** — MACD下行但价格上涨时，方向判断错误（茅台典型）

### v5: 分方向（5D综合）— 选定方案

- 跃迁方向 = `sign(sum(Δcenter_0 + Δcenter_1 + Δcenter_2 + Δcenter_3 + Δcenter_4))`
- 用全部5个维度（MACD/OBV/RSI/ROC/Vol-Ratio）的吸引子中心位移和
- 阈值 > 0.3σ 为上行，< -0.3σ 为下行
- **解决了MACD背离问题** — 茅台从"方向不分"变成上行+9.8%/67%

## 三个MACD值的对比实验

MACD指标包含三个值，分别替换到5D状态向量的第1维，其余4维（OBV/RSI/ROC/Vol-Ratio）不变：

| 方案 | MACD维度 | 来源公式 |
|:----|:--------|:--------|
| **A: MACD柱 ✅ 选定** | `2×(DIF-DEA)` | 直方图/柱 |
| B: DIF | `EMA12-EMA26` | 快线/差值 |
| C: DEA | `EMA9(DIF)` | 慢线/信号线 |

### +20d 上行效果

| 标的 | A: MACD柱 | B: DIF | C: DEA | 最佳 |

## 核心算法（v5, 选定方案）

### 1. 5D状态向量

```
S(t) = [MACD柱_z, OBV_z, RSI_z, ROC_z, Vol-Ratio_z]
       ────── 均为 z-score (mean=0, std=1) ──────
```

- **MACD柱**: `2×(EMA12-EMA26 - EMA9(DIF))`，捕捉动量加速度
- **OBV**: 能量潮的20日偏离，量价配合
- **RSI**: 14日相对强弱，超买超卖
- **ROC**: 20日变化率，价格加速度
- **Vol-Ratio**: 20日均量比，交易活动强度

### 2. 滑动窗口本地吸引子

- 窗口大小：60个交易日
- 步长：5个交易日
- 每个窗口的点集 = 60个5D状态向量
- 提取4个特征：
  - **中心**（Center）：60天的5D空间均值 → 代表当前市场状态
  - **体积**（log|Σ|）：协方差行列式对数 → 状态离散度
  - **主成分比**（λ₁/λ₂）：最大/次大特征值 → 结构化程度
  - **粗糙度**：相邻点平均距离 → 轨迹稳定性

### 3. 跃迁检测

每个特征的delta z-score = `(Δ值 - mean(Δ))/std(Δ)`

```
Transition_Strength = √(mean(z²_center_shift + z²_volume + z²_roughness))
```

> **阈值 2.0σ** → 同时偏离正常变化范围2σ以上 = 系统状态切换

### 4. 方向判断（5D综合）

```
Δcenter = center[wi] - center[wi-1]     ← 5D位移向量
方向得分 = sum(Δcenter_0 .. Δcenter_4)  ← 全部5维求和
方向     = +1 (上行)  if 得分 > +0.3
         = -1 (下行)  if 得分 < -0.3
         =  0 (持平)    otherwise
```

### 5. 方向聚类

相邻跃迁窗口（≤2步=10天）合并为一次跃迁事件，取中间窗口日期的价格。

### 6. 预测检验

跃迁事件后 +5/+10/+20/+60 天的收益，分别对上行/下行/正常日统计：
- 均值
- 胜率（正收益比例）
- 差值 vs 正常日收益

## 价格边界预测讨论

当前框架回答了三个问题：
1. **方向** — 上行还是下行跃迁
2. **幅度分布** — +20d期望值+23.48%（上行）/ -6.02%（下行）
3. **置信度** — 99.5%上行正收益，87.3%下行负收益

但没有回答：**跃迁后价格能到多少，上下边界在哪？**

可能的扩展方向：

### 方法A：吸引子属性 → 边界回归

跃迁时刻的吸引子属性可以作为边界预测的特征：
- **中心位移幅度** → 更大的位移 → 更大的预期价格波动
- **新吸引子体积** → 更大的体积 → 更宽的价格走廊
- **粗糙度** → 高粗糙度 → 毛刺多，趋势不持续

可以建立回归模型：`边界幅度 = f(位移幅度, 新体积, 粗糙度, 主成分比)`

### 方法B：历史类比区间

将400只股票的历史跃迁按"中心位移幅度"分桶，统计每个桶的+20d收益率Q25/Q75作为边界预测。例如：
- 小幅跃迁（Δcenter < 0.5σ）：+20d收益预期 [Q25, Q75]
- 中幅跃迁（0.5σ < Δcenter < 1.0σ）：+20d收益预期 [Q25, Q75]
- 大幅跃迁（Δcenter > 1.0σ）：+20d收益预期 [Q25, Q75]

### 方法C：状态空间→价格映射

利用6D状态的最后一维（价格）或重新构建"状态中心→价格"的映射函数。当吸引子中心确定时，可以推断出对应的"典型价格水平"，并利用协方差矩阵推断价格波动范围。
