## 摘要

Deep learning has become an essential tool in high-energy physics, where the ability to learn transferable event representations can significantly improve model generalization across related physics processes. In this work, we present a Particle Transformer-based framework for learning such representations for charmed baryon physics in the BESIII experiment.
